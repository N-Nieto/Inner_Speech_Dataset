# Cite

If you use the dataset or the code, please cite the paper:

> Nieto, N., Peterson, V., Rufiner, H. L., Kamienkowski, J. E., & Spies, R. (2022).
> Thinking out loud, an open-access EEG-based BCI dataset for inner speech recognition.
> *Scientific Data*, 9, 52. <https://doi.org/10.1038/s41597-022-01147-2>

```bibtex
@article{nieto2022thinking,
  title     = {Thinking out loud, an open-access {EEG}-based {BCI} dataset for inner speech recognition},
  author    = {Nieto, Nicol{\'a}s and Peterson, Victoria and Rufiner, Hugo Leonardo and
               Kamienkowski, Juan Esteban and Spies, Ruben},
  journal   = {Scientific Data},
  volume    = {9},
  number    = {1},
  pages     = {52},
  year      = {2022},
  publisher = {Nature Publishing Group},
  doi       = {10.1038/s41597-022-01147-2}
}
```

and the dataset on OpenNeuro:

```bibtex
@misc{nieto2021inner,
  title     = {Inner Speech},
  author    = {Nieto, Nicol{\'a}s and Peterson, Victoria and Rufiner, Hugo Leonardo and
```

(`10.18112/openneuro.ds003626.v<version>`).
